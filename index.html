// SOBRE O PROJETO

Eletrônica, código
e impressão 3D
num só lugar.

O MacroPad 3×3 foi desenvolvido com uma placa ESP32-S2 Mini e funciona como um teclado programável capaz de enviar comandos via Wi-Fi para controlar diferentes sistemas — incluindo um carrinho robótico.

A proposta é unir eletrônica, programação, design 3D e automação em um único dispositivo. Toda a estrutura — carcaça, keycaps e organização interna — foi criada de forma totalmente personalizada.

// COMO FUNCIONA

O sistema em
duas partes.

01
⌨️

MacroPad — Transmissor

O macropad detecta qual botão foi pressionado e envia o comando via Wi-Fi instantaneamente.

  1. ESP32 identifica a posição na matriz
  2. Interpreta o comando correspondente
  3. Envia a informação sem fio
🔼 Botão 1 → Frente ◀️ Botão 2 → Esquerda 🔔 Botão 3 → Buzina 💡 Botão 4 → LEDs
Wi-Fi
02
🤖

Dispositivo — Receptor

Um segundo ESP32 recebe os comandos e controla o dispositivo físico em tempo real.

  1. Recebe o pacote Wi-Fi
  2. Interpreta o comando
  3. Aciona o driver de motor
🚗 Carrinho robótico 🏠 Automação residencial 🎮 Controle de jogos 🎬 Edição de vídeo
